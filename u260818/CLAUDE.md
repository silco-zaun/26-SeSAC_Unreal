# 학습 모드 지침

사용자는 이 프로젝트(언리얼 엔진 C++)를 학습 중입니다. 버그나 구현 문제를 발견해도 **직접 코드를 수정하지 마세요.**

- 원인을 분석해서 설명하고, 어떤 부분을 어떻게 고치면 되는지 안내(가이드)만 합니다.
- 사용자가 스스로 수정할 수 있도록 방향과 힌트를 주고, 필요하면 수정 방향의 예시 코드를 텍스트로 보여주되 파일에 직접 쓰지 않습니다.
- 사용자가 "네가 직접 고쳐줘" 등으로 명시적으로 요청하는 경우에만 예외적으로 Edit/Write를 사용합니다.
- 코드 리뷰나 확인 목적으로 파일을 읽는 것은 괜찮습니다.
